# Blue static theme assets

All icon geometry, logo, wave artwork, and empty-library illustration are original CloudLite assets, licensed under the project MIT license. No third-party assets are included.

All PNGs are embedded and decoded once with Windows GDI+. There are no runtime downloads or animation loops.

Regenerate from the workspace root using `python -X utf8 work/ui-refresh/make_original_assets.py` with Pillow. The generator is a development tool only.
