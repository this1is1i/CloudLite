# 云简 CloudLite 0.1.0

面向 Windows x64 的个人网易云音乐播放器。Rust + Win32 原生控件，使用 Windows 系统音频引擎，无 Electron、WebView 或常驻本地 API 服务。

界面采用浅冰蓝底色、深蓝强调色和统一的静态线性图标，保留原有控件布局。原创的波纹、唱片插画与音乐标识全部内嵌到程序，素材约 113 KiB，启动时解码一次；没有在线素材请求或动画刷新循环。

## 使用

1. 解压便携包，双击 `CloudLite.exe`。把整个文件夹放在当前用户可写的位置。
2. 点“添加音乐文件夹”，选择已下载的音乐目录。双击歌曲播放；新增文件后点重新扫描。
3. 点“扫码登录”，用网易云音乐手机端扫描并确认。登录后可读取“我的歌单”，搜索和在线播放。

关闭或最小化主窗口会收到托盘。使用窗口内的“退出”或托盘菜单退出程序。

## 首版功能

- MP3、FLAC、WAV、M4A 等本地文件，读取标签与子目录；实际可解码格式取决于 Windows 已有媒体组件。
- NCM 元数据读取和临时解码播放；保留原文件，切歌后移除临时音频。异常退出可能留下 `data/cache` 中的临时文件，程序退出后可手动清理。
- 二维码登录、个人歌单、歌曲搜索、在线播放。搜索分批加载；完整歌单按歌曲 ID 分批读取。
- 在线歌曲先匹配本地文件：网易云 ID 优先，其次保守比较标题、歌手、专辑与时长；有歧义时不自动匹配。
- 上一首、下一首、暂停、拖动进度、音量、托盘和系统媒体键。
- 随机播放：每轮重新洗牌，一轮内不重复；上一首沿实际播放历史回退。关闭随机后按列表顺序播放，队列末尾停止。

## 数据与账号

默认所有应用数据保存在程序旁的 `data` 文件夹；不写入注册表、启动项、系统服务、全局环境变量或用户级工具配置。

- `settings.json`：音乐目录、音量、随机播放开关与设备标识。
- `library.json`：本地音乐索引；启动时读取缓存，不后台持续扫描。
- `session.dpapi`：由 Windows DPAPI 加密的会话，绑定当前 Windows 用户。退出账号清空本机凭据。
- JSON 保存保留上一个有效版本的 `.bak` 备份。

便携迁移时不要依赖复制登录状态，换电脑或 Windows 用户后重新扫码。保留自己的音乐目录；播放器清空来源列表不会删除音乐。

## 边界

这是使用第三方接口的非官方个人客户端。在线接口可能调整；版权、会员和试听权限由网易云决定，播放器不解除这些限制。无法获取地址或只能试听时会显示状态。

首版不含歌词、封面下载、均衡器、下载管理、自动更新或云盘管理。NCM 支持当前已实现并测试的容器格式，未知变体会报错。Windows N 等缺少媒体组件的系统可能无法播放部分编码。

发布前已通过本地格式播放和公开网络接口验证。真实账号登录后的歌单及会员权限仍需使用你自己的账号验收；最后一次目录选择器进程隔离改动已编译并通过协议测试，但尚缺这版的界面复测。见 [VALIDATION.md](VALIDATION.md)。

## 从源码构建

需要 Windows x64、Rust MSVC 工具链、MSVC C++ 链接器和 Windows SDK。本机验证使用 Rust 1.96.1、Visual Studio 2022。项目不自动安装或更改这些工具。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
# 已下载项目依赖时可使用：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Offline
```

这里的执行策略参数只作用于该次 PowerShell 进程。脚本把 Cargo 缓存和构建产物放入本项目 `.build-cache`，并在结束时恢复当前进程的环境变量。产物位于 `.build-cache/target/release/cloudlite.exe`。

API SDK 已固定在 `vendor/ncm-api-rs`，保留其许可证；其余依赖由 `Cargo.lock` 锁定。第三方说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。

可选参数：`--data-dir <目录>` 指定应用数据位置；`--library <音乐目录>` 添加来源；`--play <文件>` 启动时播放文件。
